01
Problem

Bring a team of AI agents into one app and let it run development by roles.

Solution

Production Planner

Production planning automation

02
Problem

Replace manual routine: cutting, sewing and transfer plans were built by hand from 1C exports where product names are written inconsistently.

Solution
  • Takes 1C exports: sales ranking and stock levels.
  • Matches “dirty” product names and calculates shortages.
  • Writes cutting, sewing and transfer plans straight into Google Sheets.
  • Pydantic validation and fail-fast when required columns are missing.
  • GUI and tests. Runs locally — data never leaves the machine.
Stack
PythonPydanticGoogle Sheets1CGUItests
Result

In use at a lingerie manufacturer since June 2026: plans are written to their working Google Sheet. First run on real data: 45 items in the cutting plan, 14 transfers, 20 bestsellers to distribute. 25 tests pass.

View on GitHub

Agent Factory

Gets projects to done with a team of agents

03
Problem

Take a project from spec to done with agents, verifying every step.

Solution
  • A lead agent parses the spec, builds a plan and assigns tasks.
  • Loop: delegate → independent review → rework → next task.
  • Task state file and a turn limit.
Stack
Claude Codesubagentsskills
Result

On a real task — three landing page design variants — 10 tasks closed with independent review. In 5 of them the reviewer agent found issues and the tasks passed after rework. Every accepted task is a separate git commit.
